# Azim Core — Дастури пайвасткунӣ (Railway)

Ин лоиҳа акнун сервери воқеӣ дорад (`server.js`), яъне маълумот дигар дар браузер нест, балки дар файли `data/state.json` дар сервер нигоҳ дошта мешавад. Ҳамаи компютерҳое, ки ба линки сервер дохил мешаванд, як маълумоти умумиро мебинанд.

## ⚠️ Нуктаи хеле муҳим — сабти доимии маълумот (Volume)

Хидматрасониҳои cloud (Railway, Render ва ғ.) одатан дискро **вақтӣ** месозанд: агар шумо серверро аз нав бор кунед (redeploy) ё он аз нав оғоз шавад, файли `data/state.json` **гум мешавад**, агар шумо ба он "Volume" (диски доимӣ) пайваст накарда бошед.

**Пас аз бор кардани лоиҳа дар Railway, ҳатман як Volume созед ва ба папкаи `/app/data` пайваст кунед** (қадами 5 дар поён). Бе ин қадам, ҳар боре ки шумо кодро тағйир диҳед, ҳамаи маълумоти кассаҳо гум мешавад.

---

## Қадамҳо (Railway.app)

### 1. Феҳристи GitHub созед
Ин папкаро (`azim-core-server`) ба репозиторияи GitHub бор кунед. Агар GitHub надоред, дар github.com сабти ном кунед (ройгон), репозиторияи нав созед, ва ин файлҳоро дар он бор кунед (тавассути "Upload files" дар сомонаи GitHub — ниёз ба git нест).

### 2. Дар Railway сабти ном кунед
Ба railway.app равед → "Login with GitHub".

### 3. Лоиҳаи нав созед
"New Project" → "Deploy from GitHub repo" → репозиторияи худро интихоб кунед.

Railway худкор мефаҳмад, ки ин барномаи Node.js аст (аз рӯи `package.json`) ва онро бор мекунад.

### 4. Линки дастрасӣ гиред
Пас аз бор шудан, ба "Settings" → "Networking" → "Generate Domain" равед. Шумо линке мисли ин мегиред:
```
https://azim-core-production.up.railway.app
```
Ҳамин линкро ба ҳамаи компютерҳои филиал диҳед — онҳо аз браузер (Chrome, Edge) кушода метавонанд, мисли сомонаи муқаррарӣ.

### 5. Volume (диски доимӣ) илова кунед — ҳатмист
- Дар лоиҳаи Railway худ → "Settings" → "Volumes" → "New Volume"
- Mount path: `/app/data`
- Захира кунед.

Ҳоло файли `data/state.json` доимӣ мешавад ва ҳангоми навсозии код гум намешавад.

### 6. Санҷед
Линкро дар браузер кушоед — саҳифаи логини Azim Core бояд намоён шавад. Бо `admin` / `admin123` ворид шавед ва тағйиротро санҷед.

---

## Алтернатива: Render.com

Агар Railway нахоҳед, Render.com низ монанди ҳамин кор мекунад:
1. Репозиторияро ба GitHub бор кунед.
2. Дар render.com → "New" → "Web Service" → репозиторияро пайваст кунед.
3. Build command: (холӣ монед) · Start command: `node server.js`
4. Дар "Disks" бахши Render, диски доимӣ бо mount path `/app/data` илова кунед (аналоги Volume дар Railway).

## Корбарони пешфарз (ҳангоми аввалин бор кушодан)

| Логин | Парол | Нақш |
|---|---|---|
| `admin` | `admin123` | Администратор |
| `mahzan` | `mahzan123` | Мудири махзан |
| `kassa1`, `kassa2`, `kassa3`, `kassa_boz` | `kassa123` | Кассирон |

**Тавсия:** пас аз аввалин вуруд, ҳамаи паролҳоро аз саҳифаи «Корбарон» (танҳо admin) иваз кунед.

## Ба таври маҳаллӣ санҷидан (пеш аз бор кардан ба cloud)

Агар Node.js дар компютери худ насб доред:
```
npm install
npm start
```
Баъд дар браузер `http://localhost:3000` кушоед.
