# Azim Core — Дастури пайвасткунӣ (Railway)

## 🔒 Версия 2 — тағйиротҳои амниятӣ

Дар ин версия чор мушкили амниятӣ ислоҳ шуданд:

1. **`/api/state` ҳоло ҳифз шудааст.** Пештар ҳар кас, ки линки серверро дошт — ҳатто бе логин — метавонист тамоми маълумоти хазинаро (балансҳо, рақамҳои ҳисоб, ҷадвалҳо) бинад ва ҳатто онро вайрон кунад. Ҳоло ин эндпоинт танҳо бо токени сессияи корбари воридшуда кор мекунад.
2. **Саҳифаи логин ҳоло эндпоинти алоҳидаи хурд (`/api/login-users`) истифода мебарад**, ки танҳо номи корбаронро медиҳад — на балансҳо, на рақамҳои ҳисоб.
3. **Rate-limiting барои логин илова шуд.** Пас аз 5 кӯшиши нодуруст (дар як IP/корбар), 15 дақиқа бастан амал мекунад — барои пешгирии тахминкунии зӯрозмоии парол.
4. **Роҳи "эҳтиётии" барқарорсозии парол (`emergency-reset-admin`) дигар калиди сахт-навишташуда надорад.** Ҳоло он танҳо вақте кор мекунад, ки шумо худатон дар Railway тағйирёбандаи муҳити `EMERGENCY_RESET_KEY`-ро гузоред (Settings → Variables). Бе он, эндпоинт тамоман вуҷуд надорад (404). Пас аз истифода, парол ба таври тасодуфӣ таъин мешавад ва танҳо дар логи сервер (Railway → Deployments → View Logs) намоён мешавад — на дар ҷавоби браузер.

**Барои истифодаи эҳтиётии барқарорсозӣ:**
- Дар Railway → Settings → Variables → тағйирёбандаи нав `EMERGENCY_RESET_KEY` бо арзиши дилхоҳи мураккаб (масалан, ба воситаи генератори парол) созед.
- Ба `https://ЛИНКИ-ШУМО/api/emergency-reset-admin?key=АРЗИШИ-ШУМО` дароед.
- Парол ба таври тасодуфӣ таъин мешавад — онро аз логи сервер гиред.
- Пас аз истифода, ин тағйирёбандаро аз Railway нест кунед, то эндпоинт боз пинҳон шавад.


Ин лоиҳа акнун сервери воқеӣ дорад (`server.js`), яъне маълумот дигар дар браузер нест, балки дар файли `data/state.json` дар сервер нигоҳ дошта мешавад. Ҳамаи компютерҳое, ки ба линки сервер дохил мешаванд, як маълумоти умумиро мебинанд.

## ⚠️ Нуктаи хеле муҳим — сабти доимии маълумот (Volume)

Хидматрасониҳои cloud (Railway, Render ва ғ.) одатан дискро **вақтӣ** месозанд: агар шумо серверро аз нав бор кунед (redeploy) ё он аз нав оғоз шавад, файли `data/state.json` **гум мешавад**, агар шумо ба он "Volume" (диски доимӣ) пайваст накарда бошед.

**Пас аз бор кардани лоиҳа дар Railway, ҳатман як Volume созед ва ба папкаи `/app/data` пайваст кунед** (қадами 5 дар поён). Бе ин қадам, ҳар боре ки шумо кодро тағйир диҳед, ҳамаи маълумоти кассаҳо гум мешавад.

## Қадамҳо (Railway.app)

### 1. Феҳристи GitHub созед
Ин папкаро (`azim-core-server`) ба репозиторияи GitHub бор кунед. Агар GitHub надоред, дар github.com сабти ном кунед (ройгон), репозиторияи нав созед, ва ин файлҳоро дар он бор кунед (тавассути "Upload files" дар сомонаи GitHub — ниёз ба git нест).

### 2. Дар Railway сабти ном кунед
Ба railway.app равед → "Login with GitHub".

### 3. Лоиҳаи нав созед
"New Project" → "Deploy from GitHub repo" → репозиторияи худро интихоб кунед.

Railway худкор мефаҳмад, ки ин барномаи Node.js аст (аз рӯи `package.json`) ва онро бор мекунад.

### 4. Линки дастрасӣ гиред
Пас аз бор шудан, ба "Settings" → "Networking" → "Generate Domain" равед. Шумо линке мисли ин мегиред:
```
https://azim-core-production.up.railway.app
```
Ҳамин линкро ба ҳамаи компютерҳои филиал диҳед — онҳо аз браузер (Chrome, Edge) кушода метавонанд, мисли сомонаи муқаррарӣ.

### 5. Volume (диски доимӣ) илова кунед — ҳатмист
- Дар лоиҳаи Railway худ → "Settings" → "Volumes" → "New Volume"
- Mount path: `/app/data`
- Захира кунед.

Ҳоло файли `data/state.json` доимӣ мешавад ва ҳангоми навсозии код гум намешавад.

### 6. Санҷед
Линкро дар браузер кушоед — саҳифаи логини Azim Core бояд намоён шавад. Бо `admin` / `admin123` ворид шавед ва тағйиротро санҷед.

---

## Алтернатива: Render.com

Агар Railway нахоҳед, Render.com низ монанди ҳамин кор мекунад:
1. Репозиторияро ба GitHub бор кунед.
2. Дар render.com → "New" → "Web Service" → репозиторияро пайваст кунед.
3. Build command: (холӣ монед) · Start command: `node server.js`
4. Дар "Disks" бахши Render, диски доимӣ бо mount path `/app/data` илова кунед (аналоги Volume дар Railway).

## Ба таври маҳаллӣ санҷидан (пеш аз бор кардан ба cloud)

Агар Node.js дар компютери худ насб доред:
```
npm install
npm start
```
Баъд дар браузер `http://localhost:3000` кушоед.

## Навсозии амниятӣ — рамзгузории парол (bcrypt)

Аз ин версия сар карда, паролҳо дигар ба таври оддӣ (plain text) нигоҳ дошта намешаванд:

- Ҳангоми вуруд, парол **дар сервер** санҷида мешавад (на дар браузер) — браузер ҳеҷ гоҳ парол ё рамзи (hash)-и касеро намебинад.
- Паролҳо бо **bcrypt** рамзгузорӣ мешаванд — ҳатто агар касе ба файли `data/state.json` дастрасӣ пайдо кунад, паролҳои воқеиро дида наметавонад.
- Агар шумо аллакай сервери зинда (Railway) доред, **ҳеҷ кори иловагӣ лозим нест** — ҳангоми аввалин вуруди навбатӣ, паролҳои кӯҳна худкор ба bcrypt мутобиқ мешаванд.
- Пас аз бор кардани ин версия, Railway худкор пакети нави `bcryptjs`-ро (аз `package.json`) насб мекунад — интизори иловагӣ лозим нест.

**Танҳо коре, ки лозим аст:** файли навтарини `index.html` ва `server.js`-ро ба GitHub бор кунед, боқимондаро Railway худаш мекунад.
